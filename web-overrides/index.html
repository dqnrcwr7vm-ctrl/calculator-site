FOUREIGN

네 왕국, 하나의 서약.

같은 문양의 연속 숫자 3장 이상, 또는 서로 다른 문양의 같은 숫자 3~4장을 연결하세요. 첫 등록은 30점 이상, 손패를 먼저 비우면 승리합니다.

  • 초보 · 중급 · 고급 난이도
  • 카드 클릭 자동 연결, 초보 전용 추천 배치
  • 국가별 음악과 카드 정보
  • 2~4인 초대 코드 멀티 플레이

음량과 난이도는 이 브라우저에 저장됩니다. 음악은 처음 버튼을 누른 뒤 재생됩니다.
